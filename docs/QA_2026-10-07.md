**앱–백엔드 호환성**

실제 Dart ApiClient와 임시 SQLite/Node 서버를 연결해 이메일 인증, 계정 조회, 동시 인증 오류 후 refresh token 회전, 동기화 저장·복원 및 409 충돌, Android/iOS 기기 등록·해제, 보호자 초대·수락·활성화 변경·삭제, 동일 미복용 이벤트 재전송, 백업 삭제, 삭제 인증 후 계정 삭제, 전체 로그아웃을 확인했다. 로컬 테스트의 이메일·푸시 전송은 모의 처리한다.

동기화 payload는 앱의 실제 필드 형식을 사용한다. 수량 미관리 약의 `stock: null`, 삭제된 묶음의 `deleted: true`, 취소된 복용 기록의 `cancelled: true`가 서버 왕복 후 유지된다. Firebase 프로젝트, 각 플랫폼 App ID, Android applicationId 및 iOS bundle identifier 일치도 확인했다.

2. 실제 플랫폼의 HTTPS 클라이언트로 운영 서버 상태, 의약품 검색·상세, 약국 조회 및 잘못된 검색의 400 오류 매핑 확인.
3. Android 암호화 저장소/iOS Keychain 쓰기·읽기·삭제 및 Firebase Messaging 초기화 확인. 권한 요청이나 실제 푸시 발송은 하지 않는다.

QA 데이터는 앱의 일반 복약 데이터와 분리된 `pillnote.qa.` preferences prefix와 전용 secure-storage 키를 사용하고 테스트 후 제거한다.

**운영 서버 확인**

대상: `https://pillnote.kimrasng.kr`.

| 요청 | 응답 | 판단 |
| --- | --- | --- |
| GET /health | 200, status=ok | 정상 |
| GET /ready | 404, NOT_FOUND | 현재 코드에는 200/503 준비 상태 경로가 있으므로 배포 버전·라우팅 확인 필요 |
| GET /v1/drugs/search | 200 | 한국어 검색과 앱 매핑에 필요한 필드 확인 |
| GET /v1/pharmacies/search | 200 | 이름·주소·전화·위도·경도 필드 확인 |
| GET /v1/me, /v1/sync, /v1/guardians, /v1/guardian-invitations | 401, AUTH_REQUIRED | 인증 없는 접근 차단 |
| POST /v1/auth/logout-all (인증 없음) | 401, AUTH_REQUIRED | 경로 존재 및 접근 차단 |

`/ready`는 배포된 백엔드 또는 라우팅이 현재 로컬 소스의 기대와 일치하지 않는 증거다. 정확한 원인은 공개 API 응답만으로 확정하지 않았다. 운영 배포·D1 변경·계정 생성·이메일 발송·보호자 푸시는 수행하지 않았다.

**남은 확인 범위**

- 실제 Android/iPhone에서 알림 권한 허용·거부, APNs/FCM 토큰 발급 및 보호자 알림의 포그라운드·백그라운드·종료 상태 수신.
- 실제 위치 권한 허용·거부와 GPS 위치 기반 지도 검색. 현재 검증은 좌표를 지정한 API 조회와 코드/위젯 범위다.
- 운영 이메일 인증과 인증된 운영 계정의 동기화·보호자 전체 흐름. 로컬 Node/Worker 연동과 운영 공개 API는 확인했다.
- 서명된 Android release 및 iOS 배포 빌드, 최소 OS·다른 기기 크기에서의 실기기 호환성.

미복용 판정은 현재 설계상 앱 실행 중 및 재개 시 수행된다. 앱이 완전히 종료된 동안 정해진 시각에 판정하는 기능은 제공되지 않는다. 오프라인 로그아웃은 로컬 세션을 종료하며, 서버 토큰 폐기 요청은 네트워크 상황에 따라 완료되지 않을 수 있다.

Android 빌드에서는 AGP 8.11.1/Kotlin 2.2.20 지원 종료 예고와 SDK XML 버전 경고가 나왔지만 빌드는 성공했다. 의존성 일괄 업그레이드는 이번 QA 범위에서 수행하지 않았다.
